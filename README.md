## 第二步：搞定国外手机号

注册 Claude 账号时必须验证手机号，+86 号码收不到验证短信。常见的解决方式有两种：

- **专业接码平台**。比如 Sms-activate 这类服务，买一个国外号码平均只要 2-3 元人民币，支持支付宝付款，接收 Claude 验证码的成功率比较稳。
- **部分开卡平台附带的临时号码**。有些虚拟卡平台会顺带提供国外手机号服务，但号码有效期往往很短，可能只有二十来分钟，拿到号码后要抓紧完成验证。

如果只是开这一个账号，接码平台买一个号通常就够了。

## 第三步：注册 Claude 账号

1. 打开 Claude 官网，用 Google 账号授权登录，或者输入你的邮箱地址选择邮箱注册；

## 开通之后，额度到底怎么算

Pro 的限额是两套机制同时跑，撞到任何一个都会被暂停使用：

- **5 小时会话窗口**：滚动重置，用完等窗口刷新就行；
- **每周上限**：叠加在会话限制之上，适用于所有模型，在账号固定的每周时间重置——这个时间和你什么时候订阅无关，每个周期都会给满额配额。

官方不公布具体能发多少条消息，因为用量按 token 计算，消息长短、附件大小、用哪个模型都会影响结果。50 个简短问题和 5 次长篇代码审查，消耗完全不是一个量级。

有一个容易让人意外的机制：**Claude Code 和网页聊天共享同一个额度池**。在终端里跑一次大型重构，烧掉额度和在浏览器里进行一次长对话是一样的，没有第二个配额兜底。想看余量，网页端在 Settings > Usage，Claude Code 里输入 /status，两处都能看到下次重置时间。

额度用完之后有四个选择：等重置、升级到 Max（$100/月给 5 倍 Pro 用量，$200/月给 20 倍）、开启 usage credits（超出部分按标准 API 费率单独计费，可以设置每月支出上限，单日预充最高 2000 美元），或者当天收工。如果打算开 usage credits，建议第一天就把支出上限设好，免得陷入重试循环的 agent 给你制造意外账单。

- 日常默认用 Sonnet 档，真正难的任务再切更强的模型，这一个习惯同时决定输出质量和额度消耗速度；

## 常见问题

**能用国内信用卡订阅吗？**
不能。Anthropic 只接受国外信用卡，这是硬性限制。

**开通 Claude Pro 会被封号吗？**
有一定风险，主要诱因是网络环境不稳定或频繁切换 IP。始终使用同一个稳定节点，能明显降低概率。

**两个人可以共用一个 Pro 吗？**
不建议。共享登录违反条款，而且两人共享的是同一份用量额度，等于花一份钱互相抢配额。

**不想续费了怎么取消？**
在 Settings → Billing 里取消即可，没有挽留套路，已付费周期结束前仍可正常使用。

**Pro 每个月到底能发多少条消息？**
官方没有固定数字，按 token 计费决定了这取决于你的用法。与其追别人给的估算值，不如看自己 Settings > Usage 里的实际消耗。
